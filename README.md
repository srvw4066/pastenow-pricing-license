## ¥49 买到的是什么

PasteNow 是一款剪贴板管理工具，跑在 macOS 和 iOS 上。系统自带的剪贴板只留最后一次复制的内容，再复制一次，前一条就没了。PasteNow 把你复制过的内容都存下来，需要时调出来重新粘贴。

日常用法靠快捷键。默认 CMD+Shift+V 呼出主界面，直接打字搜索，上下键选中，回车粘到当前光标位置，全程不用碰鼠标。也支持 CMD+0 到 CMD+9 按顺序快速粘贴列表里的前几条。

除了纯文本，图片、链接和代码也都能进历史记录。复制 HEX 色值时它会直接在旁边显示对应色块，做设计的人核对颜色不用再开色卡。视图有三种：简洁列表适合纯文本，丰富列表带代码高亮，网格视图看图片方便。

历史记录默认保存 1000 条，数量可以在设置里改。分类靠“智能列表”来做，规则可以按内容类型、来源 App、创建时间、是否包含某段文字来设定，灵感来自邮箱的智能邮箱，设好之后新内容自动归位。

iCloud 同步是很多人买它的主要原因。Mac 上复制的东西，iPhone 或 iPad 上能直接调出来用，反过来也行。数据走 iCloud，不经过第三方服务器，两台设备登录同一个 Apple ID 就能同步。iOS 端还提供键盘扩展，在别的 App 里打字时可以直接从键盘上取剪贴板历史，不用切出去。

隐私方面有排除列表。1Password、银行类 App 这些加进名单，PasteNow 就忽略从这些 App 复制的内容，不记录。剪贴板工具最容易被追问“我复制的密码去哪了”，这个功能算是正面回应。

授权范围写清楚：5 台设备，macOS 和 iOS 混着算；永久使用；永久免费更新；激活区域全球；界面有中文和英文；支持激活转移，原设备反激活后可以在新设备上激活。系统要求是 macOS 13 及以上、iOS 16 及以上。
